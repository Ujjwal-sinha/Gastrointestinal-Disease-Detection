🩺 GastrointestinalPolypAI

Multi-Agent, Multi-Modal Deep Learning Architecture for Gastrointestinal Polyp Detection

📋 System Overview

GastrointestinalPolypAI is a comprehensive AI-powered system for gastrointestinal polyp detection and segmentation using endoscopic images. The system integrates multiple deep learning models (YOLO11m for object detection, CNN models for classification) with advanced AI agents powered by dual Large Language Models (llama-3.1-8b-instant and qwen3-32b) for clinical analysis. The multi-modal approach combines visual analysis, text processing, clinical context integration, and temporal analysis to achieve state-of-the-art performance with 99.5% accuracy on the Kvasir-SEG dataset.
